# 金煎堂｜訂單串接 Google Sheet（Google Apps Script）

網站結帳 → GAS Web App → 驗證並**在伺服器重新計算金額** → 寫入 Google Sheet → 寄通知信 → 回傳訂單編號給網站。

## 一、建立試算表與程式（約 5 分鐘）

1. 到 Google 雲端硬碟新增一個 **Google 試算表**，命名例如「金煎堂訂單」。
2. 上方選單 **擴充功能 → Apps Script**。
3. 把編輯器裡的預設程式全部刪掉，貼上本資料夾的 `Code.gs` 全部內容，按 **儲存**。
4. （選填）修改 `Code.gs` 最上方的 `CONFIG`：
   - `NOTIFY_EMAIL`：新訂單通知要寄到哪個信箱（留空＝你自己的 Gmail）
   - `SEND_CUSTOMER_EMAIL`：是否寄確認信給有填 Email 的顧客
5. 上方函式選單選 **`setup`** → 按 **執行**。
   第一次會要求授權：選你的 Google 帳號 → 「進階」→「前往（不安全）」→ 允許。
   完成後試算表會出現「訂單」「訂單明細」兩個分頁。
6. （建議）選 **`testOrder`** → 執行，確認「訂單」分頁多一筆測試資料、信箱收到通知信。確認後可刪掉那筆。

## 二、部署成網址

1. 右上角 **部署 → 新增部署作業**。
2. 類型選 **網頁應用程式**。
3. 「執行身分」選 **我**；「誰可以存取」選 **所有人**。
4. 按 **部署**，複製 **網頁應用程式網址**（`https://script.google.com/macros/s/……/exec`）。

## 三、貼到網站

打開 `index.html`，搜尋 `ORDER_API_URL`，把網址貼進引號：

```js
const ORDER_API_URL = 'https://script.google.com/macros/s/……/exec';
```

推上 GitHub 後就會生效。網址留空時網站是「示範模式」，不會真的送出訂單。

## 日常使用

- **訂單分頁**：每張訂單一列。「狀態」欄有下拉選單（新訂單／製作中／可取餐／已出貨／已完成／已取消），會自動上色。
- **訂單明細分頁**：每個品項一列，方便用樞紐分析表統計銷量。
- 訂單編號格式：`JJT` + 年月日 + 當日流水號，例如 `JJT261127-003`。

## 修改程式後要重新部署

改了 `Code.gs` 之後：**部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**。
這樣網址不變，網站不用改。

## 注意

- 網站改價格或新增商品時，`Code.gs` 裡的 `PRODUCTS` 也要一起改（金額以這裡為準，防止有人竄改網頁價格）。
- Gmail 免費帳號每天約可寄 100 封信（Workspace 帳號約 1,500 封）。
- 信用卡、LINE Pay 目前只是記錄顧客選擇的付款方式，**沒有實際扣款**；要線上收款需另外串接金流（綠界、藍新、LINE Pay 等）。
